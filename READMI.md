
 <h1>📊 Sales Data Analysis Project</h1>

      <h2>🧾 Overview</h2>
      <p>
        This project is a complete end-to-end Data Analytics solution built using Excel, MySQL, Python, and Streamlit.
        It analyzes sales data to generate business insights such as total sales, top products, and city-wise performance.
      </p>
    </div>

<div class="card">
    <h2>🚀 Features</h2>
      <ul>
        <li>Data cleaning and preparation using Excel</li>
        <li>Data storage and querying using MySQL</li>
        <li>Data analysis using Python (Pandas)</li>
        <li>Interactive dashboard using Streamlit</li>
        <li>KPI metrics (Total Sales, Orders, Products)</li>
        <li>City-wise and Product-wise sales visualization</li>
      </ul>
    </div>
